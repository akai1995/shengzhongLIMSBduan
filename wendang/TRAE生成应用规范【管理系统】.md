# 2. 设计规范：

### 2.4.2 图标规范细则：

1. 图标线条采用2px宽度绘制，包括曲线、内部笔画、外部笔画等；
2. 在绘制图标时，应保证体量平衡，圆形、三角形等非正方形形状需要更大尺寸才能达到方形体量平衡；
3. 不应追求绝对的几何对称，应在适当的时候手动校准以保证图标内元素视觉平衡-31。

# 3. 布局与栅格：

## 3.1 布局类型：

T型布局：侧边栏承载主要导航功能，右侧为内容区域。

## 3.2 响应式适配：

最小宽度：内容区域最小宽度为1024px。

## 3.3 对齐规范：

对齐可分为水平对齐和垂直对齐两种基础逻辑，UI元素应当根据需要选择合适的对齐方式，在其所属容器内进行定位。

1. 水平对齐：分为左、右、居中和延展（Stretch）四种方式。
2. 垂直对齐：分为顶、底、居中和延展四种方式。
3. 数值对齐：为快速对比数值大小，所有数值取相同有效位数，并采用右对齐。

## 3.4 信息密度：

界面内的信息密度分为紧凑型（高信息密度）和宽松型（低信息密度），根据使用场景灵活选择。

1. 高信息密度：适用于列表、表格、文字信息浏览场景，提高浏览效率。
2. 低信息密度：适用于涉及重点任务的组件，如按钮、警告提醒组件等，确保可点击范围可用性。

## 4.7 消息提示（Message / Toast）：

1. Message（全局提示）：位于页面顶部居中，2秒后自动消失，用于操作反馈。
2. Toast（轻提示）：位于底部或中央，1.5\~2秒后自动消失。
3. Notification（通知）：位于屏幕右上角，4\~5秒后自动消失，用于系统通知。

# 6. 交互与反馈：

## 6.1 反馈机制：

| 场景   | 反馈方式          | 说明            |
| :--- | :------------ | :------------ |
| 操作成功 | Message       | 绿色提示，显示“操作成功” |
| 操作失败 | Message       | 红色提示，显示具体错误信息 |
| 加载中  | Spin          | 数据加载时展示       |
| 需确认  | Modal（Dialog） | 重要操作前二次确认     |
| 后台操作 | Loading按钮     | 提交类操作按钮置为加载状态 |

## 6.2 加载策略：

- 骨架屏（Skeleton）：页面初次加载时使用
- 局部Loading：模块数据刷新时使用
- 无限滚动：列表场景采用滚动加载
- 分页加载：表格、列表类组件采用分页

## 6.3 空状态：

内容区域展示为空时，使用空状态图标占位，根据黄金分割比进行放置。空状态应包含：

- 空状态图标（灰色系）
- 提示文字（说明无数据原因）
- 操作入口（如“立即添加”按钮）

# 7. 动效与微交互：

## 7.1 基础动效参数：

| 类型    | 时长        | 缓动曲线                             |
| :---- | :-------- | :------------------------------- |
| 过渡动画  | 200-300ms | ease-in-out                      |
| 悬停反馈  | 150ms     | ease                             |
| 模态框弹出 | 200ms     | cubic-bezier(0.2, 0.9, 0.4, 1.1) |
| 页面切换  | 300ms     | ease                             |

## 7.2 微交互场景：

- 按钮悬停：轻微颜色变化 + 阴影过渡。
- 输入框聚焦：边框变为品牌色 + 外发光效果。
- 菜单展开/收起：200ms ease过渡。
- 列表项悬停：背景色变化。

# 8. 侧边栏导航：

## 8.1 设计原则：

- 清晰可寻：菜单层级不超过两级，重要功能始终可见。
- 高效操作：支持快捷键、折叠/展开，减少鼠标移动距离。
- 视觉克制：弱化装饰，突出内容区域。

## 8.2 布局与尺寸：

### 8.2.1 侧边栏位置：

1. 采用左侧固定式侧边栏，右侧为动态内容区域。

### 8.2.2 尺寸规范：

| 状态   | 宽度   | 说明                      |

| 展开状态 | 20px | 显示图标 + 文字标签             |

## 8.4 交互行为：

### 8.4.1 菜单切换：

- 点击菜单项：立即跳转对应页面/功能，高亮状态切换至当前项。
- 路由变化时自动高亮对应菜单项。
- 二级菜单展开/收起：点击父级菜单时展开或收起子菜单。

### 8.4.2 折叠与展开：

#### 8.4.2.1 触发方式：

1. 点击顶部页眉收起/展开图标，切换展开/折叠状态。

#### 8.4.2.2 动画：

- 折叠/展开动画时长：200ms。
- 缓动曲线：ease-in-out。
- 内容区域宽度同步平滑变化。

#### 8.4.2.3 折叠态行为：

- 菜单项仅显示图标，不显示文字。
- 悬浮菜单项时，显示Tooltip（文字 + 可选快捷键）。
- Logo区域仅显示图标。

## 8.5 菜单层级与结构：

### 8.5.1 菜单结构：

- 二级菜单可包含三级菜单（如“项目”下包含“所有项目”、“最近项目”、“模板库”）。
- 三级菜单缩进：24px（相对二级菜单文字右侧）
- 三级菜单高度：40px，字号14px
- 展开/收起交互：点击二级菜单时展开/收起，或通过右侧箭头图标控制
- 展开时显示子菜单列表，收起时隐藏
- 当前子菜单选中时，父级菜单高亮（文字和图标变为品牌色）

# 省肿LIMS管理系统

基于 React + TypeScript + Ant Design + Zustand 构建的医疗LIMS管理系统。

## 技术栈

- React 18
- TypeScript
- Ant Design 5
- Zustand
- React Router
- Vite

## 功能模块

### 科研管理
- 项目立项
- 进度管理
- 成员管理
- 成果管理
- 经费管理

### 流程审批中心
- 待办事项
- 已办事项
- 审批操作
- 抄送管理

### 培训与考试管理
- 培训资料
- 在线学习
- 题库管理
- 在线考试
- 成绩查询

## 安装依赖

```bash
npm install
```

## 开发运行

```bash
npm run dev
```

## 构建生产

```bash
npm run build
```
